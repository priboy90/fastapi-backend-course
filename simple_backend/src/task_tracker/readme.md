## Минусы подхода с хранением задач в оперативной памяти:
1) При перезагрузке сервера задачи исчезают
2) При большом количестве задач лишний расход оперативной памяти
3) Нельзя запустить несколько копий сервера тк у каждого из них будут храниться свои задачи

## Хранение в файле
1) После перехода на хранение в файле (JSON):
2) Данные сохраняются между перезапусками сервера.
3) Не требует сложных систем хранения.
4) JSON легко читать и редактировать.

## Состояние гонки
Проблемы, которые остаются:
1) При одновременном доступе нескольких клиентов могут возникнуть конфликты.
2) Например, два клиента одновременно пытаются изменить одну задачу - последнее изменение перезапишет первое.

Возможные решения:
1) Использование блокировок при доступе к файлу.
2) Переход на базу данных с транзакциями.
3) Использование внешнего сервиса с API, который сам решает проблемы конкурентного доступа.
